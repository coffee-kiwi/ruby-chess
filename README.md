# Top-ruby-Chess
英語の後に日本語が続きます。

🌟 Highlights
- Files can be downloaded and Chess can be played in the CLI by running "Ruby lib/game.rb"
- Follows rules properly, including Check/Checkmate, Castling, En-Passant, and Pawn Promotion.
- You can save your game before any move by typing in "save".
- A chance is given to load the previous game upon running the "game.rb" file.
- After choosing your piece, the game will suggest all the potential moves and captures for that piece.
- You must move the piece that you select, ie. touch-move.
- Chess pieces are included into the design ♕ ♘ ♙!

🌟 ハイライト
- `Ruby lib/game.rb` を実行することで、CLI（コマンドライン）上でチェスをプレイできます。
- チェック／チェックメイト、キャスリング、アンパッサン、ポーンのプロモーションなど、チェスのルールに完全対応しています。
- 手を指す前に「save」と入力することで、ゲームを保存できます。
- `game.rb` を実行する際、前回のゲームを再開（ロード）するオプションが表示されます。
- 駒を選択すると、その駒で可能な移動や相手の駒を取る動きがすべて提示されます。
- 一度選択した駒は必ず動かさなければなりません（タッチ・ムーブのルール）。
- チェスの駒は専用の記号（♕ ♘ ♙など）で表示されます！
